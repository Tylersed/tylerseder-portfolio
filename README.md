# Tyler Seder Portfolio — Final Apple-Ready Version

This is the final static portfolio version designed for GitHub Pages. It intentionally uses a single-file `index.html` with embedded CSS and JavaScript so there are no missing CSS/JS import issues during a live demo.

## Files

- `index.html` — final interactive portfolio homepage
- `resume.html` — polished resume page with print/save-as-PDF, copy email, LinkedIn, and GitHub actions
- `404.html` — fallback page for GitHub Pages

## What changed

- Replaced the fragile 3D cube with a reliable Apple-style horizontal Systems Showcase.
- Added real sections for work, impact, decision briefs, systems, skills, experience, writing, and contact.
- Made all buttons and links go somewhere real: internal section anchors, resume page, email, LinkedIn, or GitHub.
- Kept the top animated tech stack line.
- Added scroll progress, command menu, search/sort, reveal animations, terminal animation, tech orbit, interactive systems map, and light/dark mode.
- Hardened the page so if JavaScript fails, the content remains visible.

## Upload steps

1. Open your GitHub repository.
2. Replace your current site files with these files.
3. Commit the changes.
4. Go to Settings → Pages and confirm it is publishing from the `main` branch root folder.
5. Hard refresh after deploy:
   - Windows: Ctrl + F5
   - Mac: Command + Shift + R
