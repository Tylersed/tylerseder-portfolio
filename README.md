# Tyler Seder Portfolio — 2027 Concept

Static, GitHub Pages-ready portfolio built around the concept **Complexity → Clarity**.

## Included

- Cinematic hero with video/poster fallback
- Real asset-aware loader
- Scroll-directed project chapters
- Persistent project navigation rail
- Portal workflow comparison
- Interactive Microsoft 365 system diagram
- Network normal/failover/recovery simulation
- Security investigation sequence
- Experience journey, capability workbench, and stacked education cards
- Command palette (`Ctrl/Cmd + K` or `/`)
- Optional interface sound (off by default)
- Reduced-motion, keyboard, mobile, and save-data support
- Four detailed case-study pages
- Printable résumé page
- CNAME for `tylerseder.com`

## Publish

Upload the contents of this folder to the root of the GitHub Pages repository. Do not upload the containing folder itself.

Expected root files include `index.html`, `styles.css`, `script.js`, `CNAME`, and the `assets` and `projects` folders.

## Before final public launch

Confirm that `hello@tylerseder.com` is an active mailbox. Replace it in `index.html`, `resume.html`, and any case-study page if another address should be used.
