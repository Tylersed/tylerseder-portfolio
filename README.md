# Tyler Seder Portfolio

Static portfolio website prepared for GitHub Pages.

## Publish on GitHub Pages

1. Upload every file and folder in this package to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save and wait for the published URL.

## File structure

- `index.html` — complete website
- `assets/tyler-hero.mp4` — browser-compatible H.264 hero video
- `assets/tyler-hero-poster.webp` — optimized poster image
- `assets/tyler-hero-poster.png` — fallback poster image

## Before the final launch

Add your LinkedIn URL, professional contact method, résumé PDF, and any project screenshots or case-study pages you want public.
