## Publish to GitHub Pages

Upload the **contents** of this folder to the root of the `Tylersed/tylerseder-portfolio` repository. Do not upload the containing folder as one nested directory.

The repository root should contain:

```text
index.html
styles.css
script.js
case-study.css
case-study.js
resume.html
resume.css
CNAME
assets/
projects/
```

The included `CNAME` file is already set to:

```text
tylerseder.com
```
