# Tyler Seder Portfolio — Editorial Redesign

A static GitHub Pages portfolio inspired by editorial portfolio layouts and cinematic scroll storytelling.

## Files to upload

Upload these files to the root of the `Tylersed/tylerseder-portfolio` repository:

- `index.html`
- `styles.css`
- `script.js`
- `resume.html`
- `404.html`
- `CNAME`
- `favicon.svg`, `manifest.webmanifest`, `robots.txt`, `sitemap.xml`, and `.nojekyll`
- `assets/tyler-hero-poster.png`
- `assets/tyler-hero-poster.webp`

Keep the existing `assets/tyler-hero.mp4` file in the repository. The new hero will use that video automatically and fall back to the included portrait image if the video is unavailable.

## GitHub Pages

The site is designed for the existing setup:

- Repository: `Tylersed/tylerseder-portfolio`
- Branch: `main`
- Folder: `/ (root)`
- Custom domain: `tylerseder.com`

The included `CNAME` file preserves the custom domain when replacing repository files.

## Design features

- Full-screen editorial hero
- Native sticky-scroll project stories
- Responsive mobile menu
- Scroll-linked project and typography effects
- Reduced-motion support
- Web résumé with print / save PDF button
- No build step and no framework
