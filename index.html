Security + Automation Lab

Hands-on environments for learning how systems fail and recover.

Discovery

Asset discovery identifies hosts, open services, and the boundaries of the environment before deeper analysis begins.

Assessment

Configuration review, vulnerability scanning, authentication analysis, and traffic inspection reveal where controls need attention.

Response

Firewall policy, account access, logging, segmentation, and documentation become practical response actions.

Verification

Controls are tested again, visibility is confirmed, and the investigation resolves into a clear technical summary.
